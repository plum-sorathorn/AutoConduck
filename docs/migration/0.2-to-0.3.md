# Migration Guide: AutoConduck 0.2.x to 0.3.0

## 1. Overview
AutoConduck 0.3.0 modernizes the routing engine from regex heuristics and static DAGs into an SLM-driven dynamic execution engine.

## 2. Key Breaking Changes & Deprecations
- **Removed Heuristic Evaluator**: 
outing/evaluator.py, 
outing/semantic_router.py, and 
outing/complexity.py have been removed. Use server/turn_guard.py for 0ms tool loop bypass and 
outing/slm_planner.py for complex turn planning.
- **Dynamic DAG Graph**: orchestrator/graph.py is superseded by orchestrator/dynamic_factory.py (uild_dynamic_graph).
- **Autonomous Model Tiers**: ModelPool classifies models into 3 dynamic tiers (cheap_fast, alanced, rontier_reasoning).
- **Configuration Updates**: SelectionConfig introduces slm_model_path, slm_circuit_breaker_timeout_ms, cheap_fast_max_cost, and alanced_max_cost.

## 3. Upgrade Steps
1. Update python package: pip install -e . or npm package 
pm install -g autoconduck.
2. Existing agent shims and ~/.autoconduck/config.yaml files are automatically compatible.
3. Verify server with python scripts/end_to_end_smoke.py.
